# LX Ventas

Visitas, ventas y seguimiento para equipos de venta en campo. Producto de LiderXperience.

- `src/` — aplicación (React + Vite)
- `migraciones/` — base de datos (Supabase)
- `supabase/functions/crear-usuario/` — alta de usuarios del equipo
- `CONTEXTO.md` — reglas y estado del proyecto

Desarrollo: `npm install` y `npm run dev`. Publicación: `npm run build` genera `dist/`.
